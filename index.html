OVT Therm Backup

Sistema de backup do OVT Therm

Sobre o aplicativo

O OVT Therm Backup é uma ferramenta de uso administrativo para realizar cópias de segurança dos dados operacionais do sistema OVT Therm.

Integração com Google Drive

O aplicativo utiliza autorização Google OAuth para transferir arquivos de backup a uma conta Google Drive autorizada pelo administrador.

O acesso é destinado à administração e recuperação dos backups do sistema.
